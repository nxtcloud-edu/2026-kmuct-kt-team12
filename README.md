# 활동 기반 포트폴리오 생성기

2026년 국민대학교 캠퍼스타운 키로톤 12팀 청춘03

## 프로젝트 소개

공개 링크와 로컬 파일에서 활동 기록을 모아, 모든 문장이 원문 인용에 연결된 **마스터 타임라인**을 만들고, 그 근거 안에서만 **직무 맞춤 포트폴리오**를 뽑아내는 생성기입니다.

### 핵심 기능

**1차 목표 - 마스터 타임라인 (창고)**
- 질문: "나는 지금까지 뭘 했나"
- 공개 URL(블로그, 깃허브)과 로컬 파일(PDF, 문서, 이미지)에서 활동 기록 수집
- 시간순 정렬, 중립적 사실 기술
- 모든 문장이 원문 인용(Evidence)에 연결됨

**2차 목표 - 직무 맞춤 포트폴리오 (진열대)**
- 질문: "이 직무에 나를 어떻게 보여줄까"
- 희망 직무/JD 입력 → 마스터에서 활동 선택 → 맞춤 포트폴리오 생성
- AI가 선별, 강조, 재서술하지만 새 사실 추가는 금지
- 근거 없는 역량은 "공백 리포트"로 표시

### 핵심 규칙

- 모든 출력 문장은 1개 이상의 evidenceId를 가짐
- 2차 가공은 1차에서 확보한 근거 밖으로 나가지 못함
- "직무에 맞게 꾸미지만 지어내지 않는다"

## 기술 스택

### 언어
- TypeScript 전체
- 백엔드: Node.js Lambda
- 프론트엔드: Vite + React

### 인프라 (AWS SAM)
- **API Gateway HTTP API** — 요청 진입점
- **API Lambda** — CRUD와 실행 접수
- **Worker Lambda** — 파이프라인 1~5단계 (비동기, 제한 시간 15분)
- **DynamoDB** — 단일 테이블, 온디맨드
- **S3** — 파일 업로드, 정적 호스팅
- **LLM 게이트웨이** — 대회 제공 OpenAI 호환 게이트웨이 (Claude)

### AI 호출 규칙
- 모든 AI 호출은 tool use로 JSON 스키마 강제
- 자유 텍스트 파싱 없음
- 인용문 위치는 코드로 계산 (AI 아님)
